# preprocesamiento-ciencia-datos
Proyecto de preprocesamiento de datos con Git y GitHub 

## Descripción
Este proyecto implementa técnicas básicas de preprocesamiento de datos utilizando Python, Pandas y Scikit-learn. Además, se aplica control de versiones con Git y GitHub para la gestión del proyecto.


## Funcionalidades

- Eliminación de datos duplicados
- Manejo de valores nulos
- Conversión de variables categóricas
- Normalización de datos
- Generación de dataset procesado


## Tecnologías utilizadas

- Python
- Pandas
- Scikit-learn
- Git
- GitHub


## Archivos del proyecto

| Archivo | Descripción |
|---|---|
| `preprocesamiento.py` | Script principal de procesamiento |
| `datos.csv` | Dataset original |
| `datos_procesados.csv` | Dataset procesado |
| `DOCUMENTACION.md` | Documentación del proyecto |
| `.gitignore` | Exclusión de archivos innecesarios |
