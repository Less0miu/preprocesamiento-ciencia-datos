# DOCUMENTACIÓN DEL PROYECTO

## Introducción

Este proyecto tiene como objetivo aplicar el control de versiones mediante Git y GitHub, además de implementar técnicas de preprocesamiento de datos utilizando Python, Pandas y Scikit-learn.


## Funcionalidades Implementadas

- Eliminación de duplicados
- Manejo de valores nulos
- Codificación de variables categóricas
- Normalización de datos
- Generación de dataset procesado


## Comandos Git Utilizados

### git clone
Permite clonar un repositorio remoto a la computadora local.

### git add .
Agrega todos los archivos modificados al área de preparación.

### git commit
Guarda los cambios realizados en el proyecto.

### git push
Sube los cambios al repositorio remoto en GitHub.

### git checkout -b
Crea y cambia a una nueva rama.

### git merge
Fusiona ramas dentro del proyecto.



## Automatización

GitHub Actions permite automatizar procesos relacionados con validación, integración y pruebas del proyecto de manera automática.

## Conclusión

Git y GitHub son herramientas fundamentales para el control de versiones y el trabajo colaborativo. Además, Python y Pandas permiten realizar tareas de limpieza y transformación de datos de manera eficiente y organizada.
